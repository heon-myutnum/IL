# Chapter 4. The Action Potential

## Main Topic
- Action Potential은 Voltage-Gated Ion Channel의 작동으로 만들어지는 빠른 Vm의 변화이며, Axon을 따라 재생되면서 전달

## Key Concepts
**1. Why need Action Potential?**
- 작은 Vm 변화는 주변으로 퍼질 수 있지만, 거리가 멀어질수록 약해짐  
->Passive Spread
- Action Potential: 다음 구간에서 다시 생성됨  
-> 신호가 작아지지 않음!

**2. Threshold, All-or-None**
- Threshold에 도달하면 충분한 Voltage-gated Na+ Channel이 활성화되면서, 아래 과정이 진행됨
 1. Na+ Channel Open
 2. Na+가 들어와 Depolarization이 커짐
 3. Depolarization이 더 많은 Na+ Channel의 활성화 유도
 4. 빠른 Rising Phase가 만들어짐  
 => Positive Feedback
- All-or-None: 충분한 조건이 갖추어지면 전형적인 Action Potential 발생, 그렇지 않으면 발생 x

**3. Action Potential의 각 단계**
1. Resting State: Resting Conductance가 우세  
-> Vm이 Negative한 값 유지
2. Rising Phase: Na+ channel의 빠른 활성화, Na Influx  
-> Vm 빠르게 상승
3. Overshoot: Vm이 0보다 높아짐  
-> 안쪽이 바깥보다 Positive
4. Falling Phase: Na Channel Inactivation, K Efflux  
-> Vm 다시 하강
5. Undershoot: K+ Conductance가 잠시 높게 유지  
-> Resting보다 더 Negative
6. Recovery: Conductance가 Resting 상태로 돌아감  
-> Resting 값 회복

- Depolarization: Vm이 덜 Negative해짐
- Repolarization: 탈분극 이후 원래의 Negative한 상태로
- Hyperpolarization: Resting보다 더 Negative해짐

**4. Na+ Channel: Closed != Inactivated**
- Na+ Channel은 열림/닫힘만 있는것이 아님
 * Closed but Available: 닫혀있지만, 조건이 맞으면 열림
 * Open: Na+가 통과가능
 * Inactivated: 바로 다시 열릴 수 없는 상태

**5. Why need Refractory Period?**
- Absolute Refractory Period: 충분한 Na+ Channel이 Inactivated 상태  
-> 새로운 Action Potential 발생 어려움
- Relative Refractory Period: 일부 Na+ Channel이 회복되었지만, K+ Conductance가 높거나 Vm이 Hyperpolarization 되어 있어 평소보다 강한 입력이 필요함!
- 연속적인 Action Potential 간격과 최대 Firing Frequency에 영향줌

**6. 강한 자극-> 더 큰 Action Potential?**
- 일반적으로는 x
- but 다음과 같은 변화 발생
 * Firing Frequency 증가
 * Firing Timing 변화
 * Firing Pattern 변화
- 정보는 "Spike가 얼마나 큰가?"가 아니라, "언제, 얼마나 자주, 어떤 패턴으로 발생하는가"에 담김

**7. Action Potential은 어떻게 Axon을 따라 이동하는가?**
- Na+가 들어오면 Local Current가 인접 구간을 Depolarization
- 인접 구간이 Threshold에 도달하면 그곳에서도 Action Potential 발생, 이 과정이 반복
- 중요한 점: 처음 들어온 Na+ 하나가 Axon 끝까지 가는게 아니라, 각 구간의 Membrane에서 신호가 재생된다
- 전달 방향: Axon Terminal 쪽의 Orthodromic Conduction(머리->꼬리), 이미 활성화된 뒤쪽 구간은 Refractory 상태, 진행 방향에 영향을 줌
- Axon 중간을 자극할 경우 반대 방향의 Antidromic Conduction도 나타날 수 있음

**8. Myelin은 전달을 어떻게 빠르게 하는가?**
- Myelin은 구간 사이에서 Current가 새어 나가는 것을 줄이고, 인접한 Node of Ranvier까지 빠르게 영향을 전달하도록 도움
- Node of Ranvier에는 Voltage-Gated Na+ Channel이 많이 모여 있어, Action Potential이 재생됨  
-> **Saltatory Conduction**
- Myelin으로 둘러쌓인 구간: Passive Spread, Node: Action Potential 재생

**9. 원리를 어떻게 실험적으로 확인했는가?**
- Voltage Clamp: Vm을 원하는 값으로 유지하면서 필요한 Current 측정
- Patch Clamp: 작은 Membrane 영역이나 개별 Ion Channel의 Current 측정
- Tetrodotoxin, TTX: Na+ Current를 구분하는데 사용되는 대표적 도구
- Tetraethylammonium, TEA: 특정 K+ Current 구분하는데 사용
- Optogenetics: 빛에 반응하는 Protein을 세포에 발현시켜 활동을 조절
 * Channelrhodopsin-2: 빛에 반응하는 Ion Channel
 * Halorhodopsin: Light-Driven Ion Pump


 ## Summary
 1. Action Potential은 Threshold 이후 Na+ Influx와 Positive Feedback으로 빠르게 시작됨
 2. Na+ Channel Inactivation과 K+ Efflux가 Falling Phase와 Refractory Period에 중요
 3. 신호는 Axon의 각 구간에서 재생됨, Myelin과 Nodes of Ranvier가 빠른 전달을 도움
