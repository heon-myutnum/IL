# Chapter 6. Neurotransmitter Systems

## Main Topic
- Neurotransmitter의 효과는 물질의 이름만으로 결정되지 않으며, 어떤 Receptor와 Signaling Pathway가 연결되어 있는지에 따라 달라짐
- Neurotransmitter System은 합성, 저장, 방출, Receptor, 제거 과정까지 포함하여 생각해야함.

## Key Concepts
**1. What is Neurotransmitter?**
1. Presynaptic Neuron에서 합성되고 저장되어 있어야함
2. 자극에 의해 Presynaptic Terminal에서 방출되어야 함
3. 외부에서 그 물질을 적용했을 때 실제 Synaptic Transmission과 유사한 반응을 만들어야 함  
-> 어떤 물질이 세포 안에서 발견되었다는 이유만으로 Neurotransmitter라고 결론 내릴 수는 없음  
-> 실제로 방출되고 전달 기능을 수행하는지 확인해야함

**2. Neurotransmitter System 연구 방법**
- Immunocytochemistry/Immunohistochemistry: 특정 물질이나 Protein 위치
- In Situ Hybridzation: 특정 mRNA 위치
- Release Measurement: 자극에 의해 실제 방출되는 물질
- Synaptic Mimicry: 후보 물질을 적용했을 때의 반응
- Ligand-Binding Method: Receptor와 Ligand의 결합
- Neuropharmacological Analysis: Agonist와 Antagonist에 따른 반응 차이
  
- 합성 Enzyme 찾는것: 그 물질을 만들 능력이 있는가?
- 방출 측정: 실제로 밖으로 내보내는가?

**3. '-ergic'의 의미?**
- 주로 사용하는 Neurotransmitter를 기준으로 Neuron이나 System을 부르는 방식
 * Acetylcholine -> Cholinergic
 * Dopamine -> Dopaminergic
 * Norepinephrine -> Noradrenergic
 * Glutamate -> Glutamatergic
 * GABA -> GABAergic
 * Neuropeptide -> Peptidergic
- Co-Transmitter도 존재하므로, 한 Neuron이 하나의 Neurotransmitter만 사용하는 것은 아님!

**4. Acetylcholine: 같은 물질도 결과가 다르다**
- ACh 합성 경로
$$
\[
\text{Choline}+\text{Acetyl-CoA}
\xrightarrow{\text{Choline Acetyltransferase, ChAT}}
\text{Acetylcholine}
\]
$$
방출된 ACh는 AChE에 의해 분해되며, Choline은 다시 회수됨
- 대표적 Receptor
 * Nicotinic ACh Receptor: Ionotropic Receptor
 * Muscarinic ACh Receptor: Metabotropic Receptor

- Skeletal Muscle의 Neuromuscular Junction: ACh가 Muscle의 활동 유도
- Heart에서 특정 Muscarinic Receptor 경로를 통해 Heart Rate 감소

**5. Monoamines: 공통 재료에서 다른 물질 생성**
- Catecholamines: Dopamine, Norepinephrine, Epinephrine 포함
- 합성 경로
$$
\[
\text{Tyrosine}
\rightarrow
\text{L-DOPA}
\rightarrow
\text{Dopamine}
\rightarrow
\text{Norepinephrine}
\rightarrow
\text{Epinephrine}
\]
$$
 * Tyrosine -> L-DOPA: Tyrosine Hydroxylase(enzyme)
 * L-DOPA -> Dopamine: DOPA Decarboxylase
 * Dopamine -> Norepinephrine: Dopamine beta-Hydroxylase
 * Norepinephrine -> Epinephrine: Phenylethanolamine N-Methyltransferase

- 모든 Neuron이 이 경로의 끝까지 진행하는건x, 어떤 Enzyme을 갖고 있는지가 최종적으로 생산하는 물질 결정

- Serotonin은 다른 재료에서 시작
$$
\[
\text{Tryptophan}
\rightarrow
\text{5-Hydroxytryptophan}
\rightarrow
\text{Serotonin, 5-HT}
\]
$$
- Monoamine의 작용 종료에는 Reuptake가 중요, 세포 내부의 Monoamine Oxidase, MAO 등이 Metabolism에 관여

- Depression, Parkinson's Disease: Neurotransmitter System의 변화가 기능과 관련될 수 있다!-> ppt 참고

**6. Glutamate, GABA, Glycine**
- Glutamate: CNS의 주요 Excitatory Neurotransmitter
- GABA: CNS의 주요 Inhibitory Neurotransmitter
- Glycine: Spinal Cord와 Brain Stem에서 중요한 Inhibitory Neurotransmitter
  
- GABA는 Glutamate에서 만들어질 수 있음
$$
\[
\text{Glutamate}
\xrightarrow{\text{Glutamic Acid Decarboxylase, GAD}}
\text{GABA}
\]
$$
-> GAD는 GABAergic Neuron을 식별하는데 유용한 Marker

**7. AMPA Receptor, NMDA Receptor**
- Glutamate의 주요 Ionotropic Receptor->AMPA, NMDA, Kainate Receptor
- AMPA Receptor
 * Ion Permeability: Na+, K+
 * 주요 특징: 빠른 Excitatory Response
 * Resting State: Glutamate에 의해 Current 유도 가능

- NMDA Receptor
 * Ion Permeability: Na+, K+. Ca2+
 * 주요 특징: Ligand와 Vm의 영향을 함께 받음
 * Resting State: Mg2+ Block으로 Current가 제한될 수 있음

- NMDA Receptor는 단순히 Glutamate가 왔다고 항상 충분한 Current를 만드는 것은 아님
 1. Glutamate가 결합
 2. Resting 상태에서는 Mg2+가 Pore를 막고 있을수도
 3. 충분한 Depolarization이 Mg2+ Block을 줄임
 4. Na+와 Ca2+가 통과할 수도 있음  
 -> 메시지가 도착했고, 받는 쪽도 적절한 상태일때만 동작
 - 엄밀히는 Glycine이나 D-Serine같은 Co-Agonist도 필요

**8. GABAₐ vs GABAᵦ**
- GABAₐ Receptor: Ionotropic, Cl- Conductance 증가
- GABAᵦ Receptor: Metabotropic Receptor, G-Protein을 통해 K+ Channel, Ca2+ Channel, Enzyme 조절
- GABAₐ Channel이 열릴 때 Cl-의 이동방향과 Vm 변화는 Cl- Gradient와 현재 Vm에 의해 결정, 항상 Cl-가 들어오는 것아 아님!

**9. GPCR은 어떻게 세포 안으로 명령을 전달하는가?**
- G-Protein-Coupled Receptor, GPCR은 보통 7개의 Membrane-Spanning α-Helix를 가짐
- 작동 방식
 1. Neurotransmitter가 Receptor에 결합
 2. Receptor가 G-protein 활성화
 3. G-Protein의 GDP가 GTP로 교체
 4. 활성화된 구성 요소가 Effector에 영향
 5. GTP Hydrolysis와 함께 신호가 종료되는 방향으로 진행
- G-Protein: Receptor와 내부 장치 사이에서 명령을 전달하는 연결자
  
- Shortcut Pathway: G-Protein 구성 요소가 Ion Channel을 직접 조절
- Second Messenger Cascade: Enzyme과 작은 신호 물질을 거쳐 반응이 이어짐
 * Examples
$$
\[
\text{Adenylyl Cyclase}
\rightarrow
\text{cAMP}
\rightarrow
\text{Protein Kinase A, PKA}
\]
$$
$$
\[
\text{Phospholipase C, PLC}
\rightarrow
\text{IP}_3+\text{DAG}
\]
$$
IP₃는 ER의 Ca²⁺ Release에 관여하고, DAG는 Protein Kinase C 조절에 관여함

**10. 복잡한 Cascade 쓰는 이유?**
- 직접 Channel을 여는 것보다 단계가 많아 대체로 느리지만, 아래와 같은 장점이 있음
 * Signal Amplification: 작은 시작 신호가 많은 분자에 영향을 줌
 * 다양한 Effector 조절: Channel 뿐 아니라 Enzyme과 다른 기능을 함께 조절
 * 지속적인 변화: 짧은 입력이 더 오래가는 반응으로 이어질 수 있음
- Push-Pull Model: 같은 Effector를 증가시키는 경로와 감소시키는 경로가 함께 존재할 수 있음
 * Example: Gₛ와 Gᵢ는 Adenylyl Cyclase에 반대 방향의 영향을 줄 수 있음

 **11. Divergence, Convergence, Retrograde Signaling**
 - Divergence: 하나의 Neurotransmitter가 여러 Receptor Subtype과 경로에 영향을 줌
 - Convergence: 서로 다른 Neurotransmitter가 같은 Effector Systme에 영향을 줌

 - 다른 Messenger
 * ATP: Purinergic Receptor를 통해 신호 전달
 * Endocannabinoids: 대표적으로 Retrograde Messenger로 작용
 * Nitric Oxide, NO: Diffusion을 통해 주변 세포에 영향
- Retrograde Signaling: Postsynaptic쪽에서 만들어진 신호가 Presynaptic 쪽에 영향을 줌, like Feedback

## Summary
1. Neurotransmitter System은 물질의 합성, 저장, 방출, Receptor, 제거 과정을 함께 포함
2. 같은 Neurotransmitter도 Receptor와 Signaling Pathway가 다르면 서로 다른 반응을 만듬
3. Ionotropic Receptor는 빠른 Current 변화에, GPCR은 다양한 Effector 조절과 Signal Amplification에 중요한 역할을 함
